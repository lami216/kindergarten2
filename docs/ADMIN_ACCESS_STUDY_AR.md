# دراسة الحسابات والصلاحيات ولوحة المدير

## نتيجة فحص النظام قبل التنفيذ

الدخول الحالي يقارن حسابًا واحدًا في Secrets. القوائم لا تملك سياسة صلاحيات، وتنفذ صفحات Streamlit جميع تبويباتها حتى غير المفتوحة. ملف الطالب يستدعي الحساب المالي، والمصروفات تتضمن مراجع الرواتب، والتصدير يجمع كل الجداول. سجل التغييرات يحفظ اسم المسؤول كنص دون معرف حساب ثابت. لذلك إخفاء زر أو تبويب وحده لا يحمي البيانات.

## القرار

1. حساب باسم العامل واسم مستخدم ثابت وفريد وكلمة مرور مجزأة بملح عشوائي. لا تُعرض كلمات المرور القديمة ولا تُحفظ في السجل. المدير يعيد تعيينها عند الحاجة. لا يوجد تسجيل ذاتي.
2. المدير يملك الإدارة كاملة. العامل يبدأ بلا صلاحيات، ويمنحه المدير صلاحيات صريحة لكل مجال: عرض، إضافة، تعديل، إلغاء. التعديل والإلغاء يحتاجان العرض. صلاحيات الدفعات تشمل البيانات الضرورية لاختيار الطفل وحسابه، ولا تمنح ملاحظاته الصحية أو الرواتب. لا يعني تسجيل طفل منح حق قبض المال أو الإعفاء.
3. تبقى واجهة المدير الحالية. للعامل مسار عمل يستخدم العمليات المالية نفسها، لكن يعرض فقط النماذج والسجلات المسموحة. هذا يمنع تنفيذ تبويبات قديمة كثيفة البيانات خلف واجهة مخفية. التصدير الكامل وإدارة الحسابات للمدير فقط؛ التقارير المالية الشاملة إذن صريح مستقل يكشف المجاميع، وليس امتدادًا تلقائيًا لصلاحية المصروفات.
4. فحص في التوجيه والعرض، وفحص مستقل داخل معاملة كل خدمة تغيير قبل الكتابة. الهوية من جلسة مسجلة في الخادم، وليس من اسم مسؤول يمرره النموذج. قفل الحساب والجلسة داخل المعاملة يرتب التغيير المالي وسحب الصلاحية؛ العملية التي بدأت بعد السحب تُرفض. حساب قاعدة البيانات وسر الاتصال يبقيان للخادم، ولا يحصل العامل عليهما.
5. جلسات برموز عشوائية؛ قاعدة البيانات تحفظ بصمتها فقط. انتهاء بالخمول وبحد أقصى للعمر، وإبطال عند الخروج والتعطيل وتغيير كلمة المرور أو الصلاحيات. تُمسح مسودات العامل والتنزيلات والمعاينات عند تبديل هويته أو صلاحياته. محاولات الدخول الفاشلة تخضع لحد محفوظ بقاعدة البيانات.
6. منع حذف هوية العامل من التاريخ، ومنع تعطيل آخر مدير. التعطيل يمنع الدخول والعمل مع حفظ الحساب وإحصاءاته. اسم المستخدم لا يُعاد استعماله؛ يمكن تعديل اسم العامل. ترقية حساب إلى مدير قرار صريح.

## قياس الاستخدام

القياس للأعمال المحفوظة الناجحة، وليس عدد النقرات أو نسبة استهلاك إذن. معرف الحساب يضاف إلى سجل التغييرات مع اسم المستخدم وقت العملية. يُحسب عدد الطلاب المضافين، وعدد المصروفات التشغيلية والمبلغ المسجل أصلاً وصافيه الحالي، والوصولات الأصلية وصافي الساري منها، وعدد التعديلات والإلغاءات بحسب المجال. تصحيح الوصل ليس قبضًا جديدًا مستقلاً، والراتب الآلي ليس مصروفًا تشغيليًا ثانيًا. العمليات الملغاة تظل في التاريخ مع توضيح أثرها. السجلات السابقة لتفعيل الحسابات تبقى بهويتها النصية القديمة ولا تُنسب تخمينًا إلى عامل جديد.

## الترقية والاختبارات المطلوبة

ترحيل مستقل ذري يضيف الحسابات والجلسات والتدقيق قبل فتح التطبيق. إنشاء المدير الأول بأمر تشغيل صريح من إعداد المدير الحالي، دون إنشاء مدير تلقائيًا أثناء فتح صفحة. لا تعديل على قاعدة إنتاج في هذا العمل.

تُختبر: دخول صحيح وخاطئ ومقفل، اسم مكرر باختلاف الحروف، كلمة مرور لا تُخزن كنص، آخر مدير، تعطيل وإعادة تعيين، جلسة قديمة بعد سحب الإذن، تبديل الحساب مع مسودة وPDF، عامل بلا أذونات، تسجيل فقط دون عرض الملفات، مصروفات دون رواتب، رفض استدعاء تعديل مالي مباشر دون صلاحية، هويتان متزامنتان، تكرار حفظ لا يضاعف الإحصاء، تصحيح وإلغاء مع صافي صحيح، ترقية البيانات القديمة، ثم فحوص المالية السابقة والجوال والكمبيوتر.
